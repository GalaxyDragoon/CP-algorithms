# 1.1 Primality Test : O(√n)

```cpp
bool isPrime(ll n) {
    if (n < 2) return false;
    if (n < 4) return true;               // 2, 3
    if (n % 2 == 0 || n % 3 == 0) return false;
    for (ll i = 5; i * i <= n; i += 6)    // every prime > 3 is 6k±1
        if (n % i == 0 || n % (i + 2) == 0) return false;
    return true;
}
```

For single test case , it can handle n upto 10¹² , while for t test cases it can handle n upto 10⁷
